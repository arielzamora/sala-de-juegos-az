Juego Propio: Juego de Dados

Descripción

El Juego de Dados es un juego de azar donde el jugador debe lanzar dos dados y conseguir que la suma de sus caras sea exactamente 7. El jugador tiene un número limitado de intentos para ganar la partida.

Reglas del Juego
  • 1. Al iniciar la partida, el jugador tiene 3 intentos en total.
  • 2. En cada intento, el jugador presiona el botón "Tirar" y ambos dados girarán de forma aleatoria.
  • 3. Si la suma de los dados es exactamente 7, el jugador gana la partida inmediatamente.
  • 4. Si después de los 3 intentos el jugador no logra sacar 7, pierde la partida.
  • 5. Al finalizar la partida, se guardará en la base de datos si ganó o perdió y el número de intentos utilizados.
Detalles Técnicos

Este juego está desarrollado utilizando Angular Standalone Components. Se implementó una lógica de renderizado dinámico con CSS Grid para dibujar las caras de los dados (los puntos) sin necesidad de imágenes externas, utilizando matrices booleanas. Además, incluye animaciones de sacudida y retardos asíncronos (`async`/`await`) para generar expectativa al lanzar los dados.
